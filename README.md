# KURFC 筋トレ管理アプリ

鹿児島大学ラグビー部の、筋トレ実施状況を記録・可視化するアプリです。
マネージャーが Setlog などを確認して「実施した／実施していない」を記録し、部員はランキングやカレンダーで見られます。

- アプリ: https://kurfc-rugby.github.io/kintore/
- データ: 部のGoogleアカウントのスプレッドシート「KURFC 筋トレ管理アプリ（データ）」
- 部員名簿: 会計アプリの「部員」シートと共通（Apps Script ライブラリ `KurfcRoster` 経由。`shared/KurfcRoster.gs`）
- サーバー: そのスプレッドシートに紐付いた Apps Script（ウェブアプリとして公開）

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` `style.css` `app.js` | 画面（GitHub Pages で配信） |
| `logic.js` | 集計のルール（実施回数・実施率・ランキング・継続）。画面とテストで共用 |
| `config.js` | サーバーのURL。Apps Script のURLが変わったらここだけ直す |
| `gas/Code.gs` | サーバー側のコード（権限チェック・保存）。Apps Script に貼ってあるものの控え |
| `shared/KurfcRoster.gs` | 共通部員名簿ライブラリ（Apps Script「KURFC 共通名簿」に貼ってあるものの控え）。会計アプリ・これから作るアプリと共用 |
| `dev/` | 開発用。模擬サーバーと自動テスト |

## 更新のしかた

- **画面だけ直す**: ファイルを直して `main` に push すると、1〜2分で反映されます。
  `index.html` の `?v=2.0.0` の数字も上げると、部員の端末に古い画面が残りません。
- **サーバーを直す**: `gas/Code.gs` を直す → Apps Script のエディタに貼って保存 →
  「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ。
  この方法ならURLは変わりません（「新しいデプロイ」を作るとURLが変わるので注意）。

## テスト

```
node dev/test.js            # サーバー・集計・名簿連動のテスト（模擬環境。本番のデータには触りません）
node dev/server.js          # http://localhost:8765 で、テスト用データ入りの画面を開ける
node dev/ui-test.js         # 画面の自動テスト（先に server.js を起動。playwright が必要）
```

## 集計のルール

- 実施回数: マネージャーが「実施した」と記録した日数
- 実施率: FWリーダーメニューに参加している人だけ。実施した対象日 ÷ 昨日までの対象日（＋実施した今日）。記録の無い過去の対象日は「実施していない」
- ポジション: 10区分（PR/HO/LO/FL/No.8/SH/SO/CTB/WTB/FB）、メイン1つ＋サブ
- 自主トレの人は実施率を出さず、実施回数で見る
- 週は月曜〜日曜、月は1日〜月末（日本時間）
